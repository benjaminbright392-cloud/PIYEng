PRINCE IGNITE YOUR ENGLISH — WEBSITE FILES

FILES
1. index.html  - website structure
2. style.css   - light-yellow responsive design
3. script.js   - topic catalogue, lesson interactions, progress, history, games and certificate logic

HOW TO USE
1. Download and extract Prince_Ignite_Your_English.zip.
2. Keep index.html, style.css and script.js in the SAME folder.
3. Open index.html in a browser to test it, or upload all three files to your website host/GitHub repository.
4. Do not rename script.js unless you also change the script src="script.js" line in index.html.

FEATURES
- 5,000 generated basic-topic entries and 3,000 generated advanced-topic entries.
- Search, category filters and pagination.
- Topic completion and saved progress in the browser's local storage.
- English history cards.
- Quiz, word scramble, word of the day and sentence challenge.
- Certificate unlock after 6,000 completed topics (75% of 8,000).

IMPORTANT
The catalogue count is generated from seed topics and variations. It does not mean that all 8,000 entries have a unique, fully written lesson. Progress is stored in the same browser/device. The certificate is a website-generated learning achievement certificate and is not an accredited qualification. The Google Fonts import requires internet access; the site otherwise uses fallback fonts.
